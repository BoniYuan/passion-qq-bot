# Passion API 客户常见问题

> 这是客户可见知识库。不要在此文件填写 API Key、Token、密码、管理员账号、服务器地址或其他敏感信息。

## 1. 如何开始使用

请先确认自己的账户已经注册并拿到可用额度，然后在支持 OpenAI 兼容接口的客户端中填写：服务商提供的 API 地址、自己的 API Key 和要使用的模型。不同客户端的字段名称可能不同，遇到报错时请把完整报错文字或截图发给机器人。

## 2. 支持哪些模型

可用模型以站内模型广场当前上架内容为准。机器人可以查询客户可见的模型分组和近 90 分钟状态。发送“/监控分组”查看分组，再发送“/模型状态 分组序号”查看对应模型。

## 3. 模型状态怎么看

“正常”表示近期监控结果正常；“波动”表示近期存在失败或延迟波动；“异常”表示近期监控发现明显异常；“近90分钟无调用”表示没有足够的近期调用样本，不等于模型一定不可用。遇到异常模型时，优先换用同分组中状态正常的模型。

## 4. 请求报错应该提供什么

请提供：使用的客户端或 SDK、模型名称、请求时间、完整错误信息、是否所有模型都失败，以及脱敏后的请求配置。不要发送 API Key、密码、完整 Authorization Token 或 Cookie。

## 5. 常见错误：401 / 403

通常表示 API Key 无效、已过期、复制时多了空格，或该 Key 没有权限访问当前模型。请重新复制 Key，确认请求地址和模型名称没有写错；不要把完整 Key 发到群里。

## 6. 常见错误：429

通常表示请求过于频繁、并发过高或上游限流。请降低并发、稍等后重试，或临时切换到状态正常的其他模型。持续出现时请提供模型名称和大致发生时间。

## 7. 常见错误：404 / 模型不存在

请检查模型名称是否与模型广场完全一致，并确认请求地址使用的是服务商提供的 API 地址。不要自行给模型名称添加或删除后缀。

## 8. 常见错误：超时、连接失败

先确认网络可以访问服务商地址，再检查客户端是否配置了代理、请求超时时间是否过短。若只有某一个模型超时，优先换模型；若所有模型都失败，请提供发生时间和错误截图。

## 9. 充值和测试额度

充值、退款和测试额度属于管理员操作，不要在群里发送密码、Token 或支付信息。需要人工处理时，请按管理员公布的流程联系管理员，并提供注册邮箱。机器人不会在群里公开管理员凭证或内部操作记录。

## 10. 兑换码

兑换码由管理员生成并发送。请勿在公开群里发布尚未使用的兑换码；兑换码一旦被使用通常无法撤回。如兑换失败，请提供错误提示和兑换时间，不要发送其他人的兑换码。

## 11. 余额和账户问题

账户注册邮箱、额度和充值记录属于账户隐私，不在公开群里展示。请不要把自己的密码或 API Key 发给机器人。账户问题请联系管理员处理。

## 12. 如何向机器人提问

在群里 @机器人，然后直接描述问题即可。报错分析尽量附上完整错误信息或截图。闲聊可以直接发送；涉及账户、充值、退款、兑换码的操作必须使用管理员公布的专用流程。

## 13. 模型状态不是实时保证

模型状态来自最近一段时间的监控样本，只用于辅助判断，不构成可用性保证。上游渠道可能随时变化；机器人没有查询到数据时，不会声称模型正在实时监控。

## 14. 隐私安全

任何人都不应在群聊发送 API Key、密码、Token、Cookie、支付信息或服务器登录信息。截图前请先打码。机器人无法帮助找回第三方平台密码，也不会要求你提供完整密钥。
